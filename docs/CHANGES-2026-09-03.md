# Livraison KeltiaWave du 3 septembre 2026

## Portail mobile

- La page d'accueil mobile adopte une bannière immersive et plus lisible.
- Le personnage surfeur et la légende `Beg an Dorchenn` sont volontairement
  discrets afin de préserver la hiérarchie du contenu.
- Le lanceur fixe et les cartes utilisent le même ordre : Transcribe, Record,
  Subtitles, Play, Komz puis Library.
- Les destinations restent adaptées à l'environnement local, staging ou
  production.

## Subtitles mobile

- Le choix du média précède directement l'aperçu vidéo 16:9.
- La langue et le moteur de transcription utilisent des sélecteurs segmentés
  compacts immédiatement sous la vidéo.
- L'action de génération, sa progression et ses erreurs restent regroupées dans
  le même panneau.
- Les réglages de format sont placés après l'éditeur pour alléger le parcours
  principal.
- La taille des sous-titres vidéo et des champs de la matrice est adaptée aux
  petits écrans.
- Les colonnes de timecodes Début et Fin sont resserrées pour accorder davantage
  d'espace au texte.

## Vérifications

```bash
cd apps/subtitles
npm run build

cd ../..
git diff --check
```

Les piles OVH de staging et de production sont ensuite construites à partir du
tag Git de cette livraison et contrôlées avec les smoke tests intégrés.

## Correctif Vosk OVH

- Le chemin explicite `VOSK_MODEL_PATH` est maintenant transmis au backend par
  les fichiers Compose local et OVH.
- Les exemples d'environnement documentent le chemin interne au conteneur.
- Le smoke test refuse désormais une livraison lorsque le modèle Vosk breton
  n'est pas disponible.
